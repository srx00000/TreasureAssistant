# TreasureAssistant 藏品助手

本地執行的《三國冰河時代》藏品記錄與比較工具，適用於 Windows／淘寶電腦客戶端，支援繁體與簡體中文。OCR 在本機執行，不保存截圖。

**目前版本：0.6.0 試作版。**

[繁體中文使用說明](README_TW.md) · [简体中文使用说明](README_CN.md) · [驗證紀錄](VALIDATION.md) · [已知問題](KNOWN_ISSUES.md)

## v0.6.0 更新

- 對比畫面優先顯示右側新候選；同一候選下手動切到左側會保留選取，右側換成另一件時再切回右側。
- 已核對藏品漏讀時沿用可信資料；疑似詞條錯字列為「疑似重複」，可比對後「沿用既有」。不自動改寫既有詞條或增加件數，數值不同仍分開。
- 詞條改為逐列編輯：選名稱、填數值與單位，支援新增、更新及刪除，未知屬性也可手填。
- 持有庫主要顯示實際名稱、固定編號、品階及選填等級；常駐顯示已確認件數／資料組數、待核對及疑似重複數。
- 新增「祭祀禮樂」六類欄位，持有庫可按組別篩選，配裝可選組別，預設不合計新舊兩組。
- 新增唯讀「用途影響」：查看移除一件或一批藏品後，各欄最佳屬性及所選用途分數的損失。保守保留規則維持原狀，尚未自動依倉庫容量決定回收。

## 快速開始

1. 安裝 Python **3.11 或 3.12，Windows x64**，保留 Tcl/Tk 並勾選加入 PATH。
2. 下載本倉庫並完整解壓。
3. 執行 `SETUP.cmd`；中國網路可改用 `SETUP_CHINA.cmd`。
4. 執行 `START_TW.cmd` 或 `START_CN.cmd`。
5. 在「設定」選取遊戲中央完整面板，先用「擷取一次」核對結果。

首次安裝需下載套件，之後可離線使用。`DEMO.cmd` 使用獨立示範資料庫。本版尚未封裝成 EXE。

## 更新與資料

關閉舊版後覆蓋程式檔案，**保留原本的 `data` 與 `.venv`**。依賴版本未變，已安裝環境不用重新安裝。啟動時自動新增等級欄位、誤讀對應表與新類別，保留既有藏品、固定編號、草稿及設定。更新不會清空或重排資料。

JSON 匯出升為 v3（含等級），匯入相容 v1／v2／v3。誤讀對應只存在本機 SQLite，不隨 JSON 匯出。分享程式請使用乾淨原始碼，不要連同自己的 `data`、`.venv`、日誌或匯出持有庫分享。

## 使用重點

- 只使用已核對藏品作為配裝及可靠替代依據；品質與戰力不參與屬性排名。
- 「確認本件」一鍵保存且不停止監看；需要補正才開編輯視窗。疑似重複需比對後沿用或編輯，避免把誤讀另建為新藏品。
- 持有庫單擊、雙擊或上下鍵內嵌檢視，不開視窗也不跳分頁；編輯完成留在持有庫。置頂設定會記憶。
- 同名不同屬性分開；完全相同的可見資料視為一組，件數須人工核對，重複擷取不累加。
- 回收預覽可辨識，但遊戲回收成功及身分須人工確認，再用「回收同步」扣除件數或移除資料。
- 「刪除紀錄」只刪助手資料；設定內可清空持有庫或重設資料庫。完整清空會重設編號，一般刪除不重用編號。

## 測試與限制

122 項單元與回歸測試通過，另驗證繁簡介面、470×640／430×600 排版及實際 OCR 遮擋擷取。執行：

```shell
python -m unittest discover -s tests -v
```

Windows／淘寶實機的 DPI、視窗恢復與前景行為仍需試用確認。鑑定結果頁（含「鑑定評分／高仿」、僅「屬性」標題）尚未支援，請開詳情或替換頁。其他程式遮擋仍影響辨識；總覽與未展開圖示不提供完整屬性。程式不自動點擊、換裝或操作遊戲回收。
